# I'm a magical queer sun siren

A random dating profile generator. Four slots, 32 words each, 1,048,576 possible profiles — one of which is the [real one](https://jadagul.tumblr.com/post/748572726462152704/im-a-magical-queer-sun-siren) that started all this ([commentary](https://balioc.tumblr.com/post/748587479531159552/yknow-what-im-bored-and-theres-some)).

Swipe left/right (drag, buttons, or arrow keys), tap a word to re-roll it, right-click / long-press to lock it, and share a profile by its URL.

Single static `index.html`, no build step. Edit the `SLOTS` lists to make your own.
